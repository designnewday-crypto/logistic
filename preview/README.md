# Просмотр сайта

Скачайте [burgas-logistics.zip](burgas-logistics.zip), распакуйте и откройте `index.html` в браузере.

Это самостоятельная страница: изображения и шрифт уже включены. Установка программ и запуск сервера не требуются.

Форма позволяет проверить и скачать запрос, но пока не отправляет его компании. Название Burgas Logistics временное.
